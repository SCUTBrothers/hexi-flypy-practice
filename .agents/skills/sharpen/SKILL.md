# 深化提示词（sharpen）

我想要这个任务的“更深版本”，而不是“更大版本”。在重写提示词之前，先回答以下四点：

1. 这个领域的顶尖专业人士面对这个问题时，会做哪些我目前还没要求的事？
2. 他们会从哪种最原始的一手材料入手，而不是依赖别人已经消化整理好的二手材料？
3. 他们具体会动用哪些方法与工具？
4. 除了你我主观判断之外，还有什么客观依据能证明最终结果是对的？

然后重写我的提示词，明确要求做到以上四点（只输出分析与重写后的提示词，不要直接执行任务）。

在重写后的提示词中，要求智能体对凡是能通过实验定夺的选项先做原型验证（`prototype`），并根据实测观察结果给出推荐方案；将产品取向与个人偏好类选择留给我决定。
