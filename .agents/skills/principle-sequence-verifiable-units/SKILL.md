# 按可验证单元推进工作（principle-sequence-verifiable-units）

将工作编排为一串小单元，每个单元都以可核验的状态收尾；当前单元检查全绿之前，绝不推进下一个。

在全量清理（sweep）、迁移或连续同类修改中，每个单元都是一组完整闭环：已知正常状态、单一改动、运行检查、继续下一步。即便使用自动化工具批量完成修改，也要坚持逐单元运行检查。

按能够自证正确性的顺序组织交付：先提交会失败的测试，再提交修复；先做删减，再改结构；先建立基线，再施加改动。每个提交都可独立合入。
