# 理解系统工作原理（how）

探索代码库，回答“X 是如何工作的？”这类问题。追溯设计动机请改用 `why`。

若问题范围不明确，先说明你的理解并直接展开探索，用户随时可以调整方向。

## 1. 解析架构

派生一个独立上下文的只读子智能体，一次性完成代码探索与架构讲解。向其传入用户的问题与以下任务简报：

> 你正在为一位资深工程师撰写架构说明。请探索代码库并写出一份架构解析，让不熟悉该领域的资深工程师读完后即可建立扎实的心智模型，对整体架构理解到位，从而充满信心地上手开发。你对代码库拥有只读访问权限。

## 2. 呈现结果

输出子智能体的结果。可根据对话上下文做少量润色以提升清晰度，但不要大幅改写。
