# 证明它确实有效（principle-prove-it-works）

通过直接核查真实对象来验证每一项输出：实际运行功能、读取真实数据值、审阅 diff。替代指标（文件 mtime、自我报告、缓存输出、“编译通过了”）一律不算数。检查未通过时，先怀疑观测方式是否有误，再怀疑被测系统本身。

能写成脚本就写成脚本。能够反复重跑比对逻辑的确定性脚本，远胜于一次性的肉眼查看。将脚本输出留在人类可见的位置，仅在后续必须保留可审计证据链时才将其提交入库。
