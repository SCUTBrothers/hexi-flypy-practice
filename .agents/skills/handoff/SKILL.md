# 撰写会话交接单（handoff）

以用户指定的下一步目标为核心整理交接内容，让新会话无需重读完整历史就能立刻上手。

- **明确接手入口**：开篇写清下一会话要完成的目标、具体起点和完成判定标准，再补充会影响后续决策的已定约束、已完成进展、未决问题与阻塞项。
- **用指针替代全文**：引用相关规格文档、提交记录、diff、日志或产物的具体路径，标明关键文件、常用命令及已经跑过的检查项。保留仅本会话知晓的上下文判断，剔除已有文档全文和过程闲聊，并严格区分实测事实与推测。
- **做好隐私脱敏**：交接前删除凭据、个人信息以及与接手任务无关的私密内容。
- **写明建议技能**：附上「建议使用的技能」一节，按后续步骤列出对应技能名称与选用理由；若无需专项技能，直接说明即可。
- **安全落盘与交接**：在系统临时目录（Unix 优先 `$TMPDIR`，否则 `/tmp`；Windows 用 `%TEMP%`）创建一份独立的临时交接文件，权限设为仅当前用户可读。最后将可直接复制的绝对路径，连同一句供新会话开场的启动提示一并交给用户。
