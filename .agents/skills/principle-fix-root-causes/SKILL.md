# 修复根本原因（principle-fix-root-causes）

修复引发故障的根源，而非故障浮出水面的位置。根因是系统第一次做出不该做的行为，或第一次未能处理本应处理的合法状态的地方。

- 先稳定复现。一路追问“为什么”，直到答案指向代码中的某处错误决策。卡住时就加埋点，直接读取真实状态。
- 审视触发症状的状态是否合法。若合法，就在代码出错处妥善处理；若该状态本不该存在，在该处加检查只会掩盖缺陷，必须追查是谁制造了它。前置防御检查（guard）、重试、吞掉异常、强行截断数值（clamp）和丢弃状态，都是掩盖缺陷的常见手法。
- 修复同类模式，而非单个实例。找出存在相同缺陷的所有位置并一并修复。
- 若锁定根因的关键事实费尽周折才挖出来，应顺手提出一个低开销、常驻开启的观测信号，以便下次一眼就能看清。
