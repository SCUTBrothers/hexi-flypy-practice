# 用结构固化经验（principle-encode-lessons-in-structure）

若某条经验依赖主观判断、无法直接用代码结构约束，就将指令放到更显眼的位置，并附上典型的失效反例。

**推论：** 凡是能靠结构解决的问题，就只用结构化手段修复。需要反复叮嘱的文字指令本身就是设计缺陷的症状。
