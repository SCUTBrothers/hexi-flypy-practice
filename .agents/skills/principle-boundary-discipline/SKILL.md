# 边界纪律（principle-boundary-discipline）

在数据跨越系统边界处（CLI 参数、配置文件、外部 API、网络）集中完成数据校验、类型收窄与错误处理。在系统内部直接信任类型：不重复校验，也不写冗余的空值检查。在边界处将原始数据解析为领域类型，不让传输层与框架层类型泄漏到公开接口层。业务逻辑写在零框架依赖的纯函数中，调用它们的外层外壳保持轻薄。

两条自检标准：这份数据此刻正在跨越系统边界吗？如果不是，这里的校验就是冗余的。这段逻辑能否写成供外层直接调用的纯函数？如果可以，就提取出来。
