# 从第一性原理重新设计（principle-redesign-from-first-principles）

将新变更合入系统时，切勿在原有设计表面生硬地打补丁。应当假设这项新需求从一开始就是系统的底层前提，从头重新审视设计。

- 读透所有受影响的文件，完整理解当前设计。
- 自问：“如果当初带着这项新需求从零开始写，我们会设计出什么结构？”
- 将变更彻底贯彻到每一处关联引用：类型定义、文档、示例代码与设计依据章节。
- 先想清楚完整的重设计蓝图，再拆分为小步增量交付。

这是在现有设计中演进新需求时，避免系统劣化、持续保留未来演进空间的核心方法。
