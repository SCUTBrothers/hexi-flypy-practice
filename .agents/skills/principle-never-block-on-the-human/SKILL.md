# 不要因等待人工而阻塞（principle-never-block-on-the-human）

人类以异步方式监督工作，智能体必须保持不中断推进。遇到分岔时做出合理决策、继续往前走，让人类在事后审阅纠偏。既然代码改动本身可逆且可审阅，做错一个局部决定的返工成本，通常远低于停工等待的阻塞成本。

- **先执行，再呈现结果。** 先把活干完、拿出实际结果；不要问“要不要做 X？”，而是直接把 X 做好并说明理由。
- **让系统具备自愈能力。** 发现问题时记录下来，并在下一轮迭代中顺手修复。
- **不可逆操作仍须事先确认**（如强制推送 `force-push`、删除生产环境数据、向外发送通知消息）。
- **可逆操作直接推进**（如编写代码、修改笔记、拆分任务），无需停下等待审批。
- **产品大方向由人类拍板，具体执行切勿自我阻塞。**
