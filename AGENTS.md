# Project instructions

Before using UI SDK, follow the `ui-sdk` skill if installed and read `node_modules/@ui-sdk/react/docs/llms.txt`.
Before building a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading and read `node_modules/@ui-sdk/react/docs/rendering.md`.

Preserve the Xiaohe encoding rules, grouped practice, mistakes, speech and existing `hexi-flypy-v1` browser storage format.
Run the configured checks, regression tests and production build after changes.
Do not commit, push or publish without explicit user instructions.
